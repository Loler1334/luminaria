# Семантика «Поп-культуры»: все активные карты

`src/pop-culture-201-300-sources.json` — проверенный источник для активных карт `201–300`. Скрипт `node scripts/extract-pop-culture-sources.mjs` сопоставляет исходные PNG с `src/pop-culture-manifest.json` по SHA-256 и сохраняет ровно один исходный промпт на карту. Повторный прогон `--check` выявляет расхождение с локальными исходниками.

Это исходные материалы, а не игровые описания. Промпты написаны по-английски и содержат инструкции по стилю, запрещённым надписям и композиции. Они не попадают напрямую в `luminaria_bot_card_semantics.scene`.

Русские записи лежат в `src/pop-culture-201-250-semantics.json`, `src/pop-culture-251-300-semantics.json`, `src/pop-culture-401-450-semantics.json` и `src/pop-culture-451-500-semantics.json`. Для каждой карты сохранены:

- `title`: узнаваемое произведение или основной сюжет, чтобы бот понял прямое название от игрока;
- `scene`: только видимые объекты и действие, сверенные с итоговым изображением;
- `keywords`: дополнительные буквальные синонимы, имена и предметы для голосования;
- `clues`: две-три косвенные ассоциации для бота-ведущего, без прямого названия произведения.

Карты `401–500` описаны по опубликованным изображениям. Список задуманных произведений использовался как подсказка, а не как привязка к номеру карты: несколько иллюстраций относятся к другим тайтлам. Там, где отсылка не подтверждалась визуально, название и поисковые слова описывают сцену без выдуманной франшизы.

`node scripts/build-bot-card-semantics.mjs` включает четыре файла в `supabase/bot-card-semantics-data.sql`; `node tests/bot-card-semantics.mjs` проверяет полноту всех 200 активных карт. Картинки `301–351` в активный каталог не входят.
