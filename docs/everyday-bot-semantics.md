# Семантика «Повседневного абсурда»

Все 110 активных карт описаны в двух отслеживаемых файлах: `src/everyday-absurd-001-055-semantics.json` и `src/everyday-absurd-056-110-semantics.json`. Каждая запись содержит русское описание видимой сцены, буквальные поисковые слова и две косвенные подсказки для бота-ведущего.

Для карт `011–110` исходные замыслы сохранились в локальном `output/everyday-absurdity/cards-manifest.json`; для пробных `001–010` там есть только названия и изображения. Описания сверены с опубликованными `public/deck-preview/*-abs.webp`: если замысел и готовая картинка различаются, игровой словарь следует картинке. Например, на `027-abs.webp` гигантская застёжка разделяет лето и зиму, а на `034-abs.webp` улитки проводят коронацию.

`node scripts/build-bot-card-semantics.mjs` собирает все записи в `supabase/bot-card-semantics-data.sql`. `node tests/bot-card-semantics.mjs` проверяет наличие сцены, ключевых слов и двух подсказок для каждого ID `001–110`.
